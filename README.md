# Pokémon Retriever

A simple Python terminal application that retrieves Pokémon data from PokéAPI.

## Requirements

- Python 3.10 or newer
- The Python package `requests`, used for making HTTP requests to PokéAPI

## How to run

Install dependencies:

```bash
pip install requests
```

Run the application:

```bash
python src/main.py
```
